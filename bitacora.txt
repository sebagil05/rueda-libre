MINIRETO 6: SECCION "¿POR QUE RUEDA LIBRE?" CON UTILIDADES (0 LINEAS CSS)
--------------------------------------------------------------------------------
Cinco clases consultadas en la documentacion oficial de Bootstrap 5.3:
1. text-bg-primary: Aplica en una sola utilidad el fondo del color primario y un texto contrastante legible.
2. gap-3: Define una separacion uniforme (1rem) entre los hijos directos de un contenedor flex o grid.
3. flex-md-row: Cambia la direccion de Flexbox de columna (flex-column en movil) a fila horizontal desde el breakpoint md (768 px).
4. d-none d-md-block: Oculta la imagen decorativa del ciclista en celulares (display: none) y la muestra desde tablet/md (display: block).
5. align-self-start: Evita que la insignia superior de cada beneficio se estire al ancho completo dentro de un contenedor flex vertical.

MINIRETO 7: TRES CONFLICTOS DETECTADOS ENTRE style.css Y BOOTSTRAP EN index.html
--------------------------------------------------------------------------------
1. Color y subrayado de enlaces del menu y botones (etiqueta <a>):
   - Conflicto: El reset Reboot de Bootstrap aplica color azul y subrayado por defecto a todas las etiquetas <a>.
   - Solucion: Se utilizaron las clases nativas nav-link y btn / btn-primary / btn-outline-primary, y se definieron las variables de marca en style.css cargado despues de Bootstrap, sin usar !important.

2. Margenes inferiores en encabezados y parrafos (h1-h3, p) vs. utilidades mb-*:
   - Conflicto: Las reglas globales antiguas de style.css (p { margin-bottom: 1rem; }) tenian la misma especificidad que las utilidades mb-0 o mb-4 de Bootstrap y anulaban los espaciados dentro de tarjetas y pie de pagina.
   - Solucion: Se eliminaron los margenes globales forzados sobre etiquetas HTML en style.css, delegando el espaciado a las utilidades mb-* de Bootstrap.

3. Reseteo universal (* { margin: 0; padding: 0; }) anulando listas y contenedores:
   - Conflicto: El selector universal * borraba el relleno interno de listas y componentes de Bootstrap.
   - Solucion: Se elimino el bloque * { margin: 0; padding: 0; } porque Bootstrap Reboot ya gestiona box-sizing: border-box y los margenes base.
